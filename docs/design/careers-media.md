# Careers — текущая схема шести фонов

4 ноября 2026. Добавлена шестая сцена чтения: [новая проверка и переворот бейджа](careers-sixth-scene-and-badge.md). Предыдущая замена: «Влияние.mp4» вместо Ripple Effect и новый ролик «Реальные проекты.mp4» вместо статичной атмосферы.

| Этап | Текущий веб-файл | Материал |
| --- | --- | --- |
| Быстрый рост | `purple-growth.mp4` | Ростки, предыдущий пользовательский ролик |
| Влияние на продукт | `network-impact.mp4` | Новый `Влияние.mp4`, исходные 0–3 с |
| Сильная команда | `test-team.mp4` | Прежнее сгенерированное офисное видео, без изменения |
| Реальные проекты | `creative-projects.mp4` | Новый `Реальные проекты.mp4`, исходные 10–15 с |
| Свобода решений | `sunset-freedom.mp4` | Предыдущий пользовательский ролик с закатом |
| Новые знания | `learning-notes.mp4` | Прикреплённая сцена чтения, первые 26.8 с; веб-цикл 26.29 с |

У каждого этапа теперь собственный фон; офисное видео используется только для команды. Функция `careerSceneForBenefit` выбирает сцену по ID из общего списка, без дублирования по индексам. В тестах проверены все пять файлов и отсутствие повторного использования офисного видео.

Исходники содержат резкие склейки и белые вспышки, а у «Реальных проектов» также яркий финал. Для фонового слоя выбраны спокойные цельные участки, обозначенные в таблице. Оригиналы не изменены. Web-версии сохраняют исходное разрешение 736×414 и полное кадрирование, без искусственного увеличения. H.264 faststart, 24 fps, без аудио. Подготовлены индивидуальные WebP-постеры и короткий движущийся dissolve на стыке петли. Длины веб-файлов 2.5 с и 4.5 с; сохранена скорость 0.85×. Фрагмент влияния короткий, поэтому цикл заметно чаще, чем у остальных сцен.

Подготовка:

```powershell
python -X utf8 scripts/prepare-careers-purple-videos.py 'C:/Users/bekas/Downloads/Влияние.mp4' 'C:/Users/bekas/Downloads/Реальные проекты.mp4' --names network-impact creative-projects --starts 0 10 --durations 3 5
```

Скрипт поддерживает индивидуальные имена, начало и длительность фрагментов; прежняя команда для трёх роликов остаётся совместимой. Высота теперь ограничивается меньшим из исходной высоты и 720 px, чтобы не увеличивать маленькие исходники.

Переходы 1200 мс, пауза уходящих слоёв, lazy loading рядом с секцией и reduced motion сохранены. Проверки в настоящем Edge: обе темы 1440×900, пять сцен вперёд и назад, быстрые обратные переключения, новый фон проектов, оригинальный ролик команды, реальные размеры новых video 736×414, muted/loop/0.85×, штатный переход через конец обеих новых петель, соответствующие постеры при reduced motion, все пять touch-выборов на 390×844 без горизонтального скролла. При принудительной ошибке нового ролика проектов показывается его постер, остальные сцены работают. TypeScript, production build и 77 тестов проходят. Ошибок JavaScript в основной проверке нет; сборка сообщает только прежние замечания к комментариям Zod.
