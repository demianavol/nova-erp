# Careers — новые ролики роста, влияния и свободы

4 ноября 2026. Текущая схема фонов:

| Преимущество | Исходник | Веб-версия |
| --- | --- | --- |
| Быстрый рост | Быстрый рост — Purple Growth.mp4 | `purple-growth.mp4` |
| Влияние на продукт | Влияние на продукт — Ripple Effect.mp4 | `ripple-impact.mp4` |
| Сильная команда | Прежний сгенерированный `3vid.mp4` | `test-team.mp4`, сохранён без изменения |
| Реальные проекты | Ролик ещё не предоставлен | Статичная атмосфера секции, без чужого видео или постера |
| Свобода решений | свобода.mp4 | `sunset-freedom.mp4` |

Сгенерированная офисная сцена используется **только** у «Сильной команды». Ранее подключённые `test-growth.mp4` и `test-impact.mp4` больше не входят в активный список сцен, но файлы сохранены. Пока отсутствует ролик «Реальных проектов», фон плавно растворяется в спокойную атмосферу секции. Остальные материалы пользователь добавит позже.

Три новых исходника обработаны скриптом `scripts/prepare-careers-purple-videos.py`: H.264 faststart, без звука, 24 fps, высота 720 px, полное изображение без кропа. Growth и Impact имеют 1280×720, Freedom — 1366×720 с сохранением его широкого кадрирования через object-fit: contain. Первые/последние 12 кадров сведены движущимся cosine dissolve; петля не использует стоп-кадр или обратное движение. Длины веб-файлов: 6.00 / 27.92 / 14.71 секунды. Сохранена прежняя скорость 0.85× и смена слоёв 750 мс. Текстуры Ripple заметно сложнее для сжатия: файл занимает около 8.9 МБ, остальные новые файлы около 1.1 МБ каждый.

У исходников разные сюжеты и палитра. У ролика с ростками временная петля неизбежно смешивает позднюю и раннюю стадии роста в коротком dissolve; это монтажный переход, а не непрерывное биологическое действие. Оригинальные файлы не изменены.

Контроллер дополнен статичным состоянием для отсутствующего видео. При уходе в него предыдущий слой завершает плавное затухание, затем приостанавливается. При замене файла учитывается новый src, а прежний сбой загрузки может быть сброшен после обновления списка медиа.

Проверки: TypeScript, production build, 12 файлов / 77 тестов проходят. В настоящем Edge проверены обе темы 1440×900, все пять этапов вперёд и назад, быстрые переключения через пустой этап, воспроизведение только выбранного ролика после перекрытия, переход через конец каждого из четырёх видео, отсутствие звука, сохранение пропорций Freedom, пауза вне экрана, reduced motion, ошибка Ripple с fallback на его постер и отсутствие подставленного постера у Projects. На 390×844 проверены все пять touch-выборов и отсутствие горизонтального скролла. Ошибок JavaScript в основной проверке нет. Сборка содержит прежние замечания к комментариям Zod.
